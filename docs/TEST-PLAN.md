# 真机测试清单

设备：HUAWEI Pura X（VOL-AL00），HarmonyOS 7.0.0.111，API 26。
被测包名：`com.yiertongchuan.interpreter`（正式包名；旧调试包 `com.example.assets` 已弃用）。

## 0. 安装前

- [ ] `hvigorw assembleHap` 成功，产物 `entry-default-signed.hap` 存在。
- [ ] 签名 Profile 的 UDID 包含当前设备（`hdc shell bm get -u`）。
- [ ] 应用已授予麦克风权限（首次启动弹窗）。

## 1. 启动与权限

- [ ] 冷启动 3 秒内出现主界面，状态变为“在听，请说话”。
- [ ] 拒绝麦克风后显示授权卡片；再次授权可自动开始。
- [ ] 首次启动英文音色下载有提示；下载完成后能朗读。

## 2. 核心链路

依次说 10 句中文（每句 5–15 字，句间停顿 1 秒）：

- [ ] 每句都能显示中文（isFinal 后不再变化）。
- [ ] 每句都有英文译文，语义正确。
- [ ] 英文自动朗读，语音完整、不截断。
- [ ] 第 10 句说完后仍在监听（自动续接生效）。
- [ ] 历史记录按时间倒序显示，含时间与中英文。

记录指标（秒）：

| 句子 | 识别完成 | 译文出现 | 开始朗读 | 朗读结束 |
| --- | --- | --- | --- | --- |
| 1 | | | | |
| 5 | | | | |
| 10 | | | | |

目标：识别完成 → 开始朗读 ≤ 2.5s（百度通道）。

## 3. 稳定性

- [ ] 连续说话 10 分钟不中断、不重复翻译同一句。
- [ ] 静音 5 分钟后仍能识别下一句。
- [ ] 快速连说 3 句，队列不丢句、不乱序。

## 4. 异常

- [ ] 飞行模式：单句标记失败，恢复网络后新句子正常。
- [ ] 百度 AppID/密钥填错：错误条提示，切换到免注册通道后恢复。
- [ ] 朗读过程中暂停监听：声音停止，状态为“已暂停”。
- [ ] 杀掉应用再打开：设置保留，自动开始。

## 5. 后台与锁屏

- [ ] 按 Home 键退到后台，说中文仍能翻译并朗读（通知栏有常驻通知）。
- [ ] 锁屏后说中文仍能翻译并朗读（如系统允许）。
- [ ] 关闭“后台持续监听”后，退到后台行为符合预期（暂停/被系统挂起）。

## 6. 回声

- [ ] 外放时英文朗读不被再次识别为中文（观察历史记录是否出现英文回声句）。
- [ ] 戴耳机时无回声、延迟稳定。

## 7. 功耗与资源（可选）

- [ ] 连续监听 30 分钟，电量下降可接受（目标 < 8%）。
- [ ] 应用内存稳定，无持续增长。
