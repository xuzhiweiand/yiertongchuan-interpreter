## 3. 签名

当前 `build-profile.json5` 的 `signingConfigs` 为空，首次在 DevEco 打开项目后：

1. `File → Project Structure → Signing Configs`
2. 勾选 **Automatically generate signature**
3. 登录华为开发者账号，Apply
4. Run 一次，DevEco 会为 `com.yiertongchuan.interpreter` 生成 `.p12 / .p7b` 并写回配置

注意：

- 旧签名材料绑定的是 `com.example.assets`，已移除；
- 换包名后必须重新签名，否则安装报 `9568423`；
- 正式上架建议使用**发布证书 + 发布 Profile**，不要用调试证书；
- 签名文件、密码不要提交到 Git。

## 4. APP 备案

1. 在接入商（华为云/阿里云/腾讯云）备案系统提交：
   - 主体信息
   - 应用名称：译耳同传
   - 包名：`com.yiertongchuan.interpreter`
   - 服务内容：工具类/翻译类
   - 域名与服务器（翻译/语音接口域名可填第三方，按接入商要求）
2. 接入商初审 → 短信核验 → 管局审核（约 3–20 个工作日）
3. 获得备案号后：
   - 应用内展示备案号并支持跳转查询；
   - 应用市场提交时填写备案号；
   - 备案信息变化（名称、包名、主体）需做备案变更。

> 只上鸿蒙应用市场不需要重复做其他商店备案，但 APP 备案是全国统一的，仍需完成。

## 5. 常见驳回点

| 问题 | 处理 |
| --- | --- |
| 应用名称与软著不一致 | 软著全称含“译耳同传”，或办理软著变更/补充证明 |
| 应用名称与备案不一致 | 三处统一为“译耳同传” |
| 名称含通用词/特殊符号 | 不使用“翻译”“同传”单独作名，不加 `# * &` |
| 隐私政策缺失或打不开 | 公网可访问，覆盖麦克风与第三方 SDK |
| 未展示备案号 | 关于页/设置页展示并可点击 |
| 调试签名 | 换发布证书与发布 Profile |
| 包名与备案不一致 | 修改后需重新备案，尽量一次定稿 |
